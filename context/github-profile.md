## 2. The contribution snake (one-time setup)

The snake is generated by a GitHub Action in the same `Aditya10801` repo:

1. Create the file `.github/workflows/snake.yml` with the contents below.
2. Run it once from the Actions tab: "snake" → Run workflow. After that it refreshes daily.
3. If the run fails on permissions, go to repo Settings → Actions → General → Workflow permissions → "Read and write".

```yaml
name: snake
on:
  schedule: [{ cron: "0 0 * * *" }]
  workflow_dispatch:
permissions:
  contents: write
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/snake.svg?palette=github&color_snake=#ff4f00&color_dots=#e6e3dc,#ffd9c7,#ffad85,#ff7a3d,#ff4f00
            dist/snake-dark.svg?palette=github-dark&color_snake=#ff5c1f&color_dots=#1a1a18,#4a2414,#7d3515,#c04a16,#ff5c1f
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

## 3. If the stats cards show errors

`github-readme-stats.vercel.app` is a free shared instance and is often rate limited. When that happens the cards show an error.

The reliable fix is your own copy, which takes about 5 minutes on Vercel:
1. Fork https://github.com/anuraghazra/github-readme-stats.
2. Import the fork into Vercel.
3. Add a `PAT_1` environment variable holding a GitHub token (classic, no scopes needed).
4. Replace `github-readme-stats.vercel.app` in the README with your deployment's URL.
